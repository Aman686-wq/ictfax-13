# Task Tracker App

## Description
This project is a simple app that helps users track their daily tasks.

## Installation
1. Clone the repository: `git clone https://github.com/username/task-tracker.git`
2. Navigate into the project directory: `cd task-tracker`
3. Install dependencies: `npm install`
4. Run the app: `npm start`

## Usage
After installation, open the app in your browser at `localhost:3000`. You can add, edit, and delete tasks from the main dashboard.
